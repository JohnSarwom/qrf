# QRF web asset library

This folder contains production-ready derivatives and controlled concept assets for the QRF website rebrand.

- `asset-register.json` is the authority for origin, dimensions and publication status.
- `approved-concept` assets may be used as non-project website imagery.
- `client-supplied-candidate` assets require final hardware/brand review before publication.
- Partner logos and relationship badges must not be added until their approved wording and usage rights are recorded.
- Concept imagery must never be described as a completed QRF project.
- Empty category folders are reserved for the assets listed in `docs/qrf-upgrade/07-asset-image-manifest.md`.
